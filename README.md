# Age-of-the-Gods

> **The Complete Interactive 3D Hindu Mythology Timeline, Cosmic Cycles & Sacred Genealogy Tree**

---

## 🌟 Overview

**Age of the Gods** is a web-based 3D visualization and encyclopedic journey through Sanātana Dharma. It traces the cosmic evolution from the unmanifest supreme consciousness (*Parabrahman*) through the creation cycles, primordial deities, Dashavatara incarnations, genealogies (Suryavansha & Chandravansha), great epics (*Ramayana* & *Mahabharata*), and the Four Yugas down to Mahapralaya.

---

## ✨ Key Features

- **🪐 3D Celestial Universe**: Rendered with Three.js featuring deep-space procedural nebulae, JWST-inspired cosmic environments, orbital paths, and glowing node constellations.
- **🌳 Fractal Genealogy & Timeline Tree**: Multi-level hierarchical tree mapping the genealogy of deities, kings, sages, and avatars.
- **📜 Sacred Chronicles & Lore**: In-depth historical and philosophical annotations, scriptural citations, and classical artwork for each milestone.
- **🕉️ Meditative Audio Experience**: Built-in 432Hz Tanpura drone synthesizer and sacred Om vibrations.
- **🌐 Full Bilingual Support**: Seamless dynamic switching between **Hindi / Sanskrit (देवनागरी)** and **English**.
- **🔍 Cosmic Search & Filter**: Real-time multi-attribute search across deities, avatars, yugas, and lineages with instant 3D camera focus.
- **📱 Responsive & Mobile Optimized**: Touch gestures, smooth pinch-to-zoom, dual-axis header scrolling, and adaptive layouts.

## 🚀 Quick Start

### Prerequisites
- Any modern web browser with WebGL support (Chrome, Firefox, Edge, Safari).
- Node.js (optional, for local static serving).

### Running Locally

You can open `index.html` directly in your browser, or run the lightweight local server:

```bash
node server.js
```

Then visit:
```
http://localhost:8080
```
